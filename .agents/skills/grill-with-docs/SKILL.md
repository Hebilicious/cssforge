---
name: grill-with-docs
description: Stress-test a plan or design and maintain a concise written decision record during the interview.
---

Use `$grilling`, and maintain a decision record as the interview progresses.

Before the first round, locate an existing project document that owns the subject. Prefer updating that source of truth. If none exists, propose a concise Markdown location and avoid creating it until the user authorizes repository changes.

After each round, record only settled material:

- accepted decisions and rationale;
- precise terms whose meaning was agreed;
- constraints and invariants;
- explicitly deferred questions;
- superseded decisions that must be removed from the document.

Keep exploratory dialogue out of the retained document. At the end, ensure the written record and final interview summary agree. Documentation edits do not authorize implementation of the design.
